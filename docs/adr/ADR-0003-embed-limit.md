# ADR-0003 · embed.css 上限 profile 化

- 状态：已接受（实现期裁决，**待老板 M0 演示复核**）
- 背景：规格 §4.3 C04「≤60KB」按参考项目（82 字子集，15KB）标定。通用项目的字集含场景 operation 全文（约 250 字形 × 2 字重），woff2 base64 实测 330KB，60KB 必然失败。
- 决定：上限改为 `project.profile.embed_max_kb`，默认 **512KB**；参考项目 82 字场景仍远低于任何上限。C04 报错信息给出调整指引。
- 后果：file:// 内嵌加载在本地磁盘无性能问题（原 60KB 的动机是网络内嵌体积）。
